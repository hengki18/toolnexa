ALAT GAMBAR GRATIS

Konversi Gambar Online

Ubah JPG, PNG, atau WebP ke format yang kamu butuhkan. Gratis tanpa daftar akun.

Ubah format gambar

Pilih gambar maksimal 20 MB dan 16 megapiksel.

Ukuran piksel tetap sama. Area transparan akan menjadi putih jika dikonversi ke JPG.

Cara mengubah format gambar

  1. Pilih gambar JPG, PNG, atau WebP dari perangkatmu.
  2. Pilih format hasil dan kualitas jika tersedia.
  3. Klik Konversi & unduh untuk menyimpan gambar baru.

Perbedaan JPG, PNG, dan WebP

JPG cocok untuk foto dan tidak mendukung transparansi. PNG mendukung transparansi dan menyimpan piksel tanpa kompresi lossy. WebP mendukung transparansi dan dapat menghasilkan file yang lebih kecil, bergantung pada gambar dan pengaturan kualitas.

Apakah gambar saya aman?

Alat ini memproses gambar di browser tanpa mengirim file pilihanmu ke server kami. Konversi tidak mempertahankan animasi atau seluruh metadata asli. Ukuran file hasil bisa lebih besar atau lebih kecil dari file asli.
