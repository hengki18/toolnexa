ALAT MICROSTOCK GRATIS

Pembuat Metadata Microstock

Susun judul, deskripsi dan keyword untuk aset foto, ilustrasi dan video.

Analisis foto atau video dengan AI

Pilih file dan buat draf metadata bahasa Inggris otomatis. Mode lokal ringan berjalan di browser. Mode cloud menghasilkan metadata detail tanpa mengunduh model besar, tanpa password setelah verifikasi Cloudflare aktif.

Foto maksimal 20 MB; video maksimal 250 MB.

AI mengenali isi visual; video dianalisis dari tiga bingkai, bukan audio atau seluruh gerakan. Mode cepat mengenali kategori objek, bukan deskripsi lengkap. Mode detail membuat deskripsi visual. Keyword merupakan kandidat, bukan data tren. Hasil dapat keliru. Mode lokal mengunduh model dan library dari Hugging Face dan jsDelivr tanpa mengirim media. Mode cloud mengirim bingkai JPEG kecil ke backend dan Google Gemini hanya dengan persetujuan pengguna.

Mode manual (opsional)

Informasi aset

Isi keterangan dalam bahasa Inggris untuk menghasilkan draf metadata bahasa Inggris. Alat ini memakai pola teks sederhana, bukan AI penerjemah atau pengenal gambar.

Hasil metadata

Periksa kembali apakah setiap kata benar-benar menggambarkan asetmu. Hasil bisa diedit sebelum disalin.

Urutan keyword

Sepuluh keyword pertama ditandai agar mudah diperiksa. Geser urutannya dengan tombol panah atau hapus keyword yang tidak relevan.

    Cara menyusun metadata microstock

    1. Pilih foto atau video dan mode analisis.
    2. Klik Analisis dengan AI atau gunakan mode manual.
    3. Edit dan urutkan keyword berdasarkan relevansi.
    4. Salin hasil ke formulir platform microstock atau unduh sebagai TXT.

    Apakah alat ini menghasilkan keyword yang sedang tren?

    Tidak. Mode manual merapikan informasi yang kamu masukkan. Mode AI menganalisis gambar dan mengambil kandidat keyword dari deskripsi visual, tanpa data volume pencarian. Jangan menambahkan kata yang tidak terlihat atau tidak relevan dengan aset. Batas 49 keyword adalah pengaturan alat, bukan aturan universal seluruh platform.

    Privasi dan penggunaan AI generatif

    Mode lokal memproses media di browser. Mode cloud mengirim bingkai gambar ke backend dan Google Gemini dengan persetujuan pengguna; layanan gratis dapat menggunakan data untuk peningkatan produk. Jika aset dibuat dengan AI generatif, periksa persyaratan platform dan gunakan pengaturan pengungkapan AI yang sesuai. Alat ini tidak mengirim metadata atau mengunggah aset ke platform microstock.

    Untuk menyiapkan video, gunakan juga kalkulator bitrate video.
