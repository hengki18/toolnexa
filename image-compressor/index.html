Cara kompres foto menjadi 100 KB

  1. Pilih foto dari perangkat.
  2. Pilih target 100 KB, 200 KB, 500 KB atau masukkan ukuran sendiri.
  3. Pilih JPG atau WebP dan klik Kompres foto.
  4. Periksa ukuran serta pratinjau, lalu unduh hasil.

Apa perbedaan kompresi dan mengubah resolusi?

Kompresi mengurangi ukuran file dalam KB atau MB. Jika target sulit dicapai, pengurangan resolusi dapat membantu, tetapi detail gambar bisa berkurang. Gunakan ubah ukuran foto jika hanya ingin mengatur lebar dan tinggi.

Apakah foto diunggah?

Tidak. Alat ini memproses file pilihanmu langsung di browser tanpa mengirimnya ke server kami. Animasi dan metadata asli tidak dipertahankan. Batas ukuran bergantung pada kemampuan browser dan perangkat.

Untuk format PNG, gunakan konversi gambar.
